Moon Guard

Smart Parental Control Mobile Application — a mobile solution designed to help parents support children's digital safety and responsible device usage.

Project Overview

Moon Guard is a parental-control application that brings child profile management, activity monitoring, location tracking, restricted-keyword management, application restrictions, secure parent-child communication, and routine management into one platform.

The application was developed using Flutter and integrated with Supabase backend services. Firebase Cloud Messaging (FCM) supports push notifications.
