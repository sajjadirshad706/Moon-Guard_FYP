Project Overview

Introduction to the Moon Guard application

Moon Guard is a Smart Parental Control Mobile Application developed to provide parents with a centralized platform for managing and monitoring their children's digital activities.

The application brings together child profile management, activity monitoring, location tracking, restricted-keyword management, application restrictions, secure parent-child communication, and routine management.

The application was developed using Flutter and integrated with Supabase backend services. Firebase Cloud Messaging (FCM) supports push notifications.
